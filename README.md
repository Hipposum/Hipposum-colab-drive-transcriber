# Colab Drive Transcriber

Транскрибация видео с разделением по спикерам в Google Colab (бесплатный T4 GPU).
Вход и выход — папка на Яндекс.Диске: положил видео → запустил блокнот → рядом с каждым
видео появился готовый транскрипт.

Под капотом: **WhisperX large-v3** (транскрибация + чистка галлюцинаций + повторный
проход по проблемным зонам + пословное выравнивание wav2vec2) и
**pyannote speaker-diarization-community-1** (диаризация, фолбэк на 3.1).

## Как пользоваться

1. Открой `colab_transcribe.ipynb` в [Google Colab](https://colab.research.google.com/)
   (File → Open notebook → GitHub, или загрузи файл вручную).
2. Разовая настройка описана в шапке блокнота: включить T4 GPU, добавить секреты
   `HF_TOKEN` и `YANDEX_TOKEN`, принять условия моделей pyannote на Hugging Face.
3. Создай папку `/Transcribe` на Яндекс.Диске, закинь туда видео.
4. «Среда выполнения → Выполнить всё».

Результат — один файл **`<имя видео>.docx`**, рядом с самим видео на Яндекс.Диске
(та же папка). Красивый читаемый транскрипт, как у SpeechToText.

Формат транскрипта:

```
19.07.26_08.48.mp4

Спикер 1:
00:00:21 - Ну что? Пошла возня. С кого начинаем? ...
00:01:02 - Угу. Так. Как дела? ...

Спикер 2:
00:01:52 - Нет.
```

Реплики одного спикера склеиваются в абзацы по ~30–45 секунд; новый абзац
начинается после паузы больше 2,5 с. Правила разбивки — константы в `src/report.py`.

Скорость на T4: ~5–8 минут на час видео без диаризации, ~10–15 минут с ней.
Прогресс хранится в `<VIDEOS_FOLDER>/transcription_progress.json` на самом Диске —
если сессия Colab оборвётся, просто запусти всё заново: уже выгруженные видео не
транскрибируются повторно, локальные чекпоинты подхватят недоделанное с места остановки.

## Архитектура

```
colab-drive-transcriber/
├── colab_transcribe.ipynb   # блокнот для Colab (главный вход)
├── config/settings.yaml     # все настройки; переопределяются env PIPELINE_*
└── src/
    ├── runner.py            # точка входа: python -m src.runner
    ├── stages.py            # этапы обработки одного видео + чекпоинты
    ├── transcription.py     # Whisper Pass1/Pass2, загрузка аудио, VAD
    ├── problem_zones.py     # детект галлюцинаций и проблемных зон
    ├── diarization.py       # pyannote community-1 (fallback 3.1) + пост-обработка
    ├── report.py            # сборка транскрипта в .docx
    ├── storage.py           # Яндекс.Диск (скан/скачивание/выгрузка) или локальная папка, ZIP
    ├── checkpoints.py       # пер-этапный кэш (resume)
    └── utils.py             # GPU, форматирование, статистика
```

Поток: скачивание видео → аудио 16kHz → Whisper Pass1 → чистка галлюцинаций +
Pass2 проблемных зон → выравнивание слов → диаризация → `{имя}.docx` →
выгрузка результата обратно на Яндекс.Диск, локальная копия видео удаляется.

Код вырос из внутреннего пайплайна whisperx-pipeline (транскрибация уроков);
здесь оставлена только транскрипция — без LLM-анализа и интеграций с CRM.

## Локальный запуск через Яндекс.Диск (не Colab)

Нужен NVIDIA GPU, Python 3.10+, ffmpeg.

```bash
pip install -r requirements.txt
export HF_TOKEN=hf_...
export YANDEX_TOKEN=y0_...
PIPELINE_VIDEOS_FOLDER=/Transcribe python -m src.runner
```

## Альтернатива: локальная папка вместо Яндекс.Диска

`mode: "local"` в `config/settings.yaml` (или `PIPELINE_MODE=local`) — видео читаются
из `local_dir`/`local_file`, результат остаётся локально в `work_dir` рядом с видео
(например, для смонтированного в Colab Google Drive). Ничего никуда не выгружается.

```bash
PIPELINE_MODE=local PIPELINE_LOCAL_DIR=/path/to/videos PIPELINE_WORK_DIR=/path/to/results \
  python -m src.runner
```
